# Ghayda N. Ja'afreh — AI Engineering Portfolio

A professional portfolio showcasing applied AI, data science, computer vision, backend engineering, research-oriented systems, certifications, and role-focused resumes.

## Overview

This portfolio presents selected technical work across:

- Artificial Intelligence & Machine Learning
- Data Science & Model Evaluation
- Computer Vision
- Backend Systems & APIs
- Applied Research
- Robotics Integration
- Software Engineering

The site is designed as a structured portfolio rather than a single long-scroll showcase. Major sections have dedicated pages, and selected projects include full case studies with technical context, visuals, and source links where public release is appropriate.

## Featured Work

### StrokeLens
Secure and explainable healthcare AI graduation project using structured clinical data.

> Technical methodology, results, implementation details, and project materials are intentionally not publicly disclosed at this stage.

### Tetris AI Lab
A complete AI gameplay system combining a trained CNN placement policy, recovery training, Top-5 one-piece lookahead, and a limited safety filter.

### Privacy-Safe Multimodal Authentication
A multimodal authentication workflow using face verification, speaker verification, optional offline speech recognition, and privacy-aware public publishing.

### Dr. NAO
An educational AI + robotics demonstration integrating a NAO humanoid robot, a web interface, and a pre-trained skin-lesion classifier.

### Medical Image Segmentation
Dental X-ray computer-vision work covering both instance segmentation and semantic segmentation.

### ML Decision Surfaces Lab
An interactive machine-learning visualization lab for exploring decision boundaries, regression surfaces, and model behavior.

### Imaging Filters Lab
An interactive digital-image-processing laboratory covering spatial, frequency-domain, wavelet, restoration, morphology, and related workflows.

### Intel Image Classification
A controlled transfer-learning project comparing a baseline CNN with EfficientNetB0 and fine-tuning using TensorFlow/Keras.

### Handwriting OCR — HOG + KNN
A classical computer-vision OCR pipeline using character segmentation, HOG feature extraction, KNN classification, and word reconstruction.

### MNIST CNN Experiments
A controlled PyTorch comparison centered on the effect of Batch Normalization in CNN-based handwritten-digit classification.

### Blood Donation System
A PHP + MySQL full-stack web application supporting donor registration, blood-type compatibility search, blood requests, and authenticated administration.

```

```

## Project Structure

```text
app/          Application routes and pages
components/   Shared UI components
data/         Structured portfolio/project data
public/       Covers, screenshots, videos, certificates, and resumes
```

## Design Principles

- Premium technical presentation
- Consistent project-card system
- Dedicated pages for major portfolio sections
- Privacy-aware public release of research material
- Evidence-based metrics only
- Clear distinction between implemented work and future directions
- Responsive layouts for desktop and mobile
